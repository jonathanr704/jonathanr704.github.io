Project Overview

About the Project

Academia KM is an educational web application developed to organize online learning content and provide students with a centralized course experience.

The application uses PHP for server-side functionality and MySQL for user authentication and database interaction. PDO is used to manage database access through prepared queries.

The course interface is designed to help authenticated students browse available lessons, watch video content and access downloadable materials.

Security-related functionality includes session-based access control, CSRF protection, login rate limiting and protected file delivery.

The platform is currently under development, with a focus on usability, secure access and responsive layouts.
